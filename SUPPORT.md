# Suporte

| Plataforma | Nível |
|---|---|
| Fedora atual com `dnf` | suportada |
| Ubuntu LTS/Debian atual com `apt-get` | suportada |
| WSL 2 com Fedora ou Ubuntu/Debian | suportada |
| Linux `amd64` e `arm64` | suportado quando o fornecedor publica artefato |

O projeto suporta Python 3.10+. Versões de `oc` devem ser alinhadas à versão do
cluster. Releases antigas de fornecedores podem deixar de existir nos mirrors.
